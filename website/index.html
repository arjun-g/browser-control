Setup Instructions

Install the Extension

Choose your browser and install the extension:

Load Extension from GitHub (Temporary)

While the extension is under review, load it directly from source:

1. Clone or download the repository:
git clone https://github.com/arjun-g/browser-control.git
2. Open your browser's extension page:
Chrome: chrome://extensions/
Edge: edge://extensions/
3. Enable Developer mode

(toggle in top-right corner)

4. Click "Load unpacked" button
5. Navigate to browser-control/packages/extension

and select the folder

The extension will load with a temporary ID. Once it's available on official stores, you can install from there instead.

Start the MCP Server

Run the local MCP server to establish the connection between your AI client and browser:

npm install -g @browser-control/mcp-server mcp-server
Configure Your AI Client

Add the MCP server to your AI client configuration:

Claude Code (v1.101+) - Method 1: CLI Command (Recommended)

claude mcp add browser-control -- npx -y @browser-control/mcp-server

Or Method 2: Manual config file at ~/.config/Claude/claude_desktop_config.json

{ "mcpServers": { "browser-control": { "command": "npx", "args": ["-y", "@browser-control/mcp-server"] } } }

After configuration, restart Claude Code to load the server.

GitHub Copilot in VS Code (v1.101+) - Add to VS Code settings

Open VS Code Settings (File → Preferences → Settings) and search for "MCP Servers" or edit .vscode/settings.json:

{ "mcpServers": { "browser-control": { "command": "npx", "args": ["-y", "@browser-control/mcp-server"] } } }

Important: Toggle Agent Mode next to the Copilot Chat input to activate configured MCP servers. Reload VS Code after saving settings.

Cursor - Use Graphical Configuration

Cursor provides a GUI for MCP configuration instead of manual JSON editing:

Settings ──> Features ──> MCP ──> + Add New MCP Server

Click "Add New MCP Server" and fill in:

  • Name: browser-control
  • Command: npx
  • Args: -y @browser-control/mcp-server

Restart Cursor to activate.

Continue.dev IDE Extension - File: ~/.continue/config.json

{ "mcpServers": { "browser-control": { "command": "npx", "args": ["-y", "@browser-control/mcp-server"] } } }

For Other MCP Clients: Any MCP-compatible application can use Browser Control Bridge. Visit modelcontextprotocol.io for the full MCP specification and list of compatible clients.

Start Using

Your AI agent now has full control of your browser! Ask it to navigate, interact, and analyze web content.

💡 Pro Tip: Open the extension's Command History sidebar to see all actions performed and debug integration. Visit the Options page to configure the WebSocket bridge URL and authentication token.

How It Works

📡

MCP Server

Node.js server running locally that exposes 40+ tools via the Model Context Protocol using stdio + WebSocket transports.

🔌

Browser Extension

Manifest V3 extension with service worker, offscreen bridge document, and interactive command history sidebar UI.

🌉

WebSocket Bridge

Secure local WebSocket connection between MCP server and extension with optional token-based authentication.
