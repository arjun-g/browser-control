Get Started in Minutes

Setup Instructions

Install the Extension

Install from the Chrome Web Store — the same listing also works in Microsoft Edge:

Add to Chrome Add to Edge

✅ Live on Chrome Web Store and installable in Edge from the same listing. A native Edge Add-ons listing is still under review.

Start the MCP Server

Run the local MCP server to establish the connection between your AI client and browser:

npm install -g @browser-control/mcp-server mcp-server
Configure Your AI Client

Add the MCP server to your AI client configuration:

Claude Code (v1.101+) - Method 1: CLI Command (Recommended)

claude mcp add browser-control -- npx -y @browser-control/mcp-server

Or Method 2: Manual config file at ~/.config/Claude/claude_desktop_config.json

{ "mcpServers": { "browser-control": { "command": "npx", "args": ["-y", "@browser-control/mcp-server"] } } }

After configuration, restart Claude Code to load the server.

GitHub Copilot in VS Code (v1.101+) - Add to VS Code settings

Open VS Code Settings (File → Preferences → Settings) and search for "MCP Servers" or edit .vscode/settings.json:

{ "mcpServers": { "browser-control": { "command": "npx", "args": ["-y", "@browser-control/mcp-server"] } } }

Important: Toggle Agent Mode next to the Copilot Chat input to activate configured MCP servers. Reload VS Code after saving settings.

Cursor - Use Graphical Configuration

Cursor provides a GUI for MCP configuration instead of manual JSON editing:

Settings ──> Features ──> MCP ──> + Add New MCP Server

Click "Add New MCP Server" and fill in:

  • Name: browser-control
  • Command: npx
  • Args: -y @browser-control/mcp-server

Restart Cursor to activate.

Continue.dev IDE Extension - File: ~/.continue/config.json

{ "mcpServers": { "browser-control": { "command": "npx", "args": ["-y", "@browser-control/mcp-server"] } } }

For Other MCP Clients: Any MCP-compatible application can use Browser Control Bridge. Visit modelcontextprotocol.io for the full MCP specification and list of compatible clients.

Start Using

Your AI agent now has full control of your browser! Ask it to navigate, interact, and analyze web content.

💡 Pro Tip: Open the extension's Command History sidebar to see all actions performed and debug integration. Visit the Options page to configure the WebSocket bridge URL and authentication token.

How It Works

📡

MCP Server

Node.js server running locally that exposes 40+ tools via the Model Context Protocol using stdio + WebSocket transports.

🔌

Browser Extension

Manifest V3 extension with service worker, offscreen bridge document, and interactive command history sidebar UI.

🌉

WebSocket Bridge

Secure local WebSocket connection between MCP server and extension with optional token-based authentication.

🔐 Featured: Automate Inside Your Real, Logged-In Sessions

Browser Control drives the browser you're already signed into. There's no credential handoff, no re-login, and no headless bot that gets blocked by SSO or 2FA — the agent simply acts through your existing authenticated session.

Authenticated Workflow Automation

This is the flagship use case because it's something headless scrapers and generic automation tools can't do safely: work inside admin panels, internal dashboards, and logged-in product flows using the session that's already open in your browser.

1. Already signed in, no extra setup

The agent reuses your existing logged-in tab — no API keys, service accounts, or stored passwords required.

2. Navigate the internal tool

It opens the right dashboard, admin page, or authenticated report exactly as you would.

3. Perform the real task

Click through filters, fill fields, trigger exports, or update records inside the authenticated app.

4. Return verified results

It captures a screenshot and structured data from the page, so you can trust the output came from the real session.

Demo Showcase

Watch the agent operate a real, already-signed-in Cloudflare Web Analytics dashboard: it reads every key metric for the last 24 hours, switches the date range to the last 7 days, reads them again, and returns a side-by-side comparison with screenshots — something a headless scraper can't safely do behind your login.

Example prompt: "In the browser tab, read all the key metrics for the last 24 hours — visits, page views, load time, Core Web Vitals, top countries, referrers, browsers, and devices. Then switch the date range to the last 7 days and read the same metrics. Give me a side-by-side comparison highlighting what changed, and screenshot both views."
  • Works with SSO, 2FA, and session-based auth already in your browser
  • No credentials ever passed to the AI client or MCP server
  • Ideal for internal tools, admin panels, and back-office workflows
