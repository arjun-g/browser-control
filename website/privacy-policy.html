Privacy Policy

Last Updated: July 27, 2026

Overview

Browser Control Bridge is a browser extension that connects your browser to AI agents via Model Context Protocol (MCP). This privacy policy explains how we handle data and what permissions the extension requires.

Data Collection & Privacy

What We DO NOT Collect

  • No personal data collection - We do not collect, store, or transmit any personal information
  • No tracking - We do not track your browsing activity or create user profiles
  • No analytics - We do not use analytics services or tracking pixels
  • No telemetry - Extension usage data is never sent to external servers
  • No third-party sharing - Your data is never shared with third parties

Local-Only Operation

Browser Control Bridge operates exclusively locally on your machine:

  • All data processing happens on your device
  • Communication is only between your browser and a local MCP server you control
  • WebSocket connections use localhost and 127.0.0.1 only
  • No internet communication (except to navigate to websites you request)
  • Session data and command history stay on your machine

What Data the Extension Accesses

To enable browser automation, the extension accesses:

  • Page content - To execute commands you request via the MCP server
  • DOM elements - To interact with web pages (clicking, typing, reading)
  • Cookies - Only when explicitly requested by an automation command
  • Screenshots - Only when captured by your MCP agent request
  • Performance data - Metrics like Core Web Vitals are read-only
ℹ️ Important: This data is never stored externally or shared. It only exists in your browser's memory during the active session or in your local browser storage.

Storage & Data Retention

Browser Storage

The extension may store the following locally in your browser:

  • Command history - For the command history sidebar (IndexedDB)
  • Session data - Session IDs and metadata for tracking automation runs
  • Settings - MCP server configuration and authentication tokens (if enabled)

You can clear all stored data by:

  • Going to chrome://extensions → Find Browser Control Bridge → "Clear Data"
  • Clearing your browser cache and cookies
  • Uninstalling the extension

Permissions Explained

The extension requires the following permissions to function:

Browser Permissions

  • tabs - To list and manage browser tabs
  • activeTab - To access the current tab for automation
  • scripting - To execute automation scripts on web pages
  • debugger - For Chrome DevTools Protocol features (screenshots, performance)
  • cookies - To read/manage cookies when requested
  • downloads - To list and manage downloads
  • storage - To store command history locally

Host Permissions

  • <all_urls> - To execute automation on any website you visit
  • ws://localhost/* - For local WebSocket bridge communication

Extension Permissions

  • sidePanel - To display the command history sidebar
  • offscreen - To maintain the MCP server connection
  • alarms - To schedule periodic maintenance tasks

Security

Local-Only Architecture

The extension uses a local-only architecture for maximum security:

  • Extension communicates exclusively with a local MCP server you control
  • No third-party services or external APIs are used
  • WebSocket connections are restricted to localhost
  • All commands are executed with your explicit authorization

Authentication

If you enable optional token-based authentication:

  • Authentication tokens are stored locally only
  • Tokens are used for communication with your local MCP server only
  • Never transmitted to external services

Your Rights & Control

You have full control over the extension and your data:

  • Uninstall anytime - All data is immediately deleted
  • Clear data manually - Use browser storage settings to clear any stored data
  • Disable the extension - Go to chrome://extensions and toggle off
  • View the source code - Extension is open source on GitHub

Changes to This Policy

We may update this privacy policy as the extension evolves. We will notify users of significant changes. Your continued use of the extension constitutes acceptance of the updated policy.

Compliance

Browser Control Bridge complies with:

  • Google Chrome Web Store Policies - All privacy requirements met
  • GDPR - No personal data collection, no data transmission
  • CCPA - No personal information sales or third-party sharing
  • General Privacy Standards - Local-only operation with user control
